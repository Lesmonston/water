# Flick WebView UI

原生 ES 模块，无 npm 或运行时依赖。由可信宿主提供 39 个 IPC 命令；无内置回放数据。开发测试中的假宿主只位于 tests/browser.test.mjs。

- app.mjs 管理路由、命令、轮询和模态焦点。服务返回整份结论后替换当前视图；不在界面计算清理计划。
- ipc.mjs 是宿主边界，校验命令参数的精确形状、ID、决定和搜索词。
- model.mjs 包含显示规则；旧格式测试所需的曲线纯函数保留。
- views/ 按页渲染；charts.mjs 只把服务给的数据换算成图形位置和比例。styles/tokens.css 是 v3 原样令牌。
- 菜单与浮层支持键盘。清理和永久删除期间关闭窗口会提示；空闲不轮询，连接失败可重新连接。

首页选择本次位置，新增文件夹单独选中。结论页保留服务顺序与全部判断卡。跳过菜单按服务提供的权限显示：条目发送条目 ID，卡片或汇总行发送单元 ID。跳过后重读结论；移除跳过记录时，有结论就重读，结论不存在则返回可开始体检的页面。跳过名单变动不在本地标记结论过期。重复文件清理只进入隔离区。

设计稿的数字是样例。没有数据的统计不补算：没有历史累计释放数、按月合计、类别历史体量或清理后的预测日期。图中历史点只使用已有记录，体检竖线仅记录当次收到的进度采样。抽屉底部显示服务给出的整体计划，不自行计算当前组已选体量。

测试包含 3 个单元测试与 6 个浏览器测试。共享 JSON 样例使用虚构的用户、项目和媒体路径；浏览器假宿主只返回内存数据。截图输出到测试环境指定的 .local 目录。Windows 无头浏览器测试不调用原生文件夹选择框、打开真实目录或删除真实数据；真实服务接线与 macOS 需要另外验证。
