## 4. 界面：拟物可视化（M6 暂缓的原因与进度）

用户 11-05 的要求，按先后：
1. “UI整体要做可视化的优化，整体的可视化方案你要想一下用什么替代目前的主要面板。”→ 总控先出了平面方案 [viz-proposal.html](design/water-ui-v2/viz-proposal.html)（容量带、条形），**被否定**；
2. “我希望是拟物的可视化，不能像现在一样简单的条形图，我希望有创意一些，包括要有扫描逐渐变大，清理的时候逐渐变小的动画”→ 总控提出“水箱与冰山”；
3. 用户草图（[feedback/20261105-user-sketch-one-iceberg.png](design/water-ui-v2/feedback/20261105-user-sketch-one-iceberg.png)）：“不要一个盘一个冰山，是本次扫描范围，或者本机所有的是一个冰山，冰山和水面接触的那一条平面线做磁盘分区”；
4. 看了第一版（[截图](design/water-ui-v2/feedback/20261105-user-screenshot-iceberg-v1.webp)）：“上部的冰山要始终在四个盘的中间位置，而且它也可以随着扫描越变越大……不同的垃圾种类有不同的颜色……现在基本上都是淡色，没有深色”；
5. “海的深度，视野范围也是随着扫描慢慢变大的。文字要和可视化区域分开，不要放到冰山下了”；
6. “都放到左边，有专门的菜单区即可。”

当前设计意图（都已交代给制作样稿的后台代理）：
- **一座冰山**（本次范围 / 本机全部可切换）；水线按盘分区，分区宽度按容量（每盘有最小占比，整体缩放进画面），水下面积按已用，透明层是可用，快满的盘琥珀色；
- **冰山一角**始终居中，面积按可清字节，按垃圾种类上深色（AI 编程工具 `#2a78d6`、浏览器缓存 `#eb6834`、开发缓存 `#1baf7a`、应用更新残留 `#eda100`、系统临时文件 `#6250d6`、其它 `#8A96A6`，已过色盲校验）；需要你看的块（琥珀）在所属分区水线下，受保护（紫）是深处锁住的核心；
- **动画**：体检时冰山一角从小长大，视野从水线附近逐渐拉远加深；清理时冰山融化、各分区可用空间上涨，进隔离区的块飞进制冰盒；减少动态效果时直接跳到结果；
- **文字全部在左侧一栏菜单区**（约 300～340 px，紧挨导航栏、样式与导航区分），右边画面只留盘符刻字与悬停时的引线高亮；
- 隔离区＝制冰盒（霜随天数加厚）、趋势＝潮位尺、空间分布＝分区里的石块、查重＝双胞胎冰块；
- 主按钮实心蓝，全屏唯一。

**样稿**：`docs/design/water-ui-v2/viz-skeuo.html`（`?s=<场景>&t=<毫秒>` 定帧），预览 `previews/skeuo-*.png`。由后台代理制作，写本报告时**还在改、未提交**。它完成后：
