# 首版需求与验收

状态：规划基线 v0.1；不代表功能已实现。优先级 P0 为对应里程碑验收门，P1 为门槛满足后追加。

| ID | 优先级/阶段 | 需求 | 可验证结果 |
|---|---|---|---|
| W-F01 | P0/M1 | 显式扫描范围 | 未选择根目录不遍历用户数据；范围、排除项与取消状态可见 |
| W-F02 | P0/M1 | 工具与项目识别 | 清单、配置路径、版本和结构匹配给出处；仅名称匹配标弱证据 |
| W-F03 | P0/M1 | 对象分类 | 缓存、环境、模型、实验、历史、数据库、凭证/未知分别记录 |
| W-F04 | P0/M1 | 风险与证据 | 用途、风险、恢复性、活跃状态和置信度分别展示；未知保护 |
| W-F05 | P0/M1 | 容量与覆盖 | 逻辑字节和估算置信度分开；硬链接/父子范围去重；权限失败非 0B |
| W-F06 | P0/M1 | 已知引用 | 清楚说明来自哪些扫描项目，无法证明全局未引用时不宣称孤儿 |
| W-F07 | P0/M1 | 进度与导出 | 扫描可取消、逐项失败；默认脱敏报告不含凭证或对话正文 |
| W-F08 | P0/M2 | 具体清理计划 | 对象ID、规则/工具版本、目标、成本、边界、恢复能力与计划摘要齐全 |
| W-F09 | P0/M2 | 执行复核 | 拒绝伪造ID、过期计划、身份/引用/范围变化、越界链接和未知目标 |
| W-F10 | P0/M2 | 工具执行器 | 可信可执行路径、结构化参数、特定受支持动作；无任意shell/路径接口 |
| W-F11 | P0/M2 | 结果真实性 | success/skipped/partial/failed 分项；trash不计已释放，不承诺所有操作可撤销 |
| W-F12 | P0/M2 | 中断与恢复 | 写入操作日志后执行；重新启动能显示不确定项；恢复冲突不覆盖新文件 |
| W-F13 | P0/M3 | 双平台 | Windows与macOS分别有真实执行记录；没有测试平台标未验证 |
| W-F14 | P1/M3 | 增量与趋势 | 更新能识别通知丢失/索引过期并回退；趋势不读取用户内容 |

## 工具覆盖分批

| 第一批适配对象 | M1 只读 | M2 执行条件 |
|---|---|---|
| pip / uv / npm / pnpm | 配置发现、缓存归属、范围与成本 | 原生动作逐版本适配；需要清理的命令不在扫描阶段运行 |
| Python / Node 项目 | project markers、环境/依赖清单与锁文件状态 | 不默认删 venv/node_modules；依赖可恢复仍需具体规则证明 |
| HF Hub / Ollama / LM Studio | 模型与版本 inventory；共享/重复路径提示 | 首先保持显式选择；未知格式/自定义模型保护；无通用blob删除 |
| Claude Code / Codex / Cursor | 区分已验证cache与状态目录，只读盘点 | 会话、memory、恢复点保护；没有稳定契约不开放删除 |
| Docker / WSL / Docker VM | 本机context、builder节点与对象占用；VM父子容量视图 | 卷、VM保护；builder目标不明或远端不执行 |

Conda、ComfyUI、魔搭、浏览器 profile、Homebrew 和更多工具可进入后续规则批次；首版目标不是一次宣称“全部支持”。

## 安全验收矩阵

| 场景 | 预期 |
|---|---|
| 只有同名目录、缺失工具结构 | 弱匹配或未知，不能默认回收 |
| cache 根内出现 token、用户作品或未知数据库 | 保护或降级，不整根清空 |
| 根目录/系统/HOME/源码根或受保护资产祖先被选中 | 后端拒绝整树移动/删除；显式scope、规则或计划ID不能绕过 |
| 前端伪造确认、扩大选中集合或重放计划 | 确认绑定后端对象及摘要，失效/已消费权限拒绝；原生确认等机制按威胁模型验证 |
| 指向外部目录的symlink/junction/reparse | 不默认跟随；边界验证失败就跳过 |
| 扫描后路径被替换或对象ID过期 | 计划失效，禁止按旧路径继续 |
| 下载/构建/训练正在运行 | 不因“年龄够老”强行清理；遵守工具锁，不杀进程 |
| 两个路径指向同一文件/模型blob | 不重复计算预计释放；保留其他有效引用 |
| APFS clone/快照、VM回收不可精确测 | 标估算/未知和宿主实测，不能承诺立即腾空 |
| 私有源失效或离线 | 展示恢复约束，不把有锁文件直接判为可无损重建 |
| 未推送worktree、未同步实验、独有LoRA | 资产保护，不能依闲置自动清理 |
| 构建缓存命令会触及远端builder | 目标核对失败，保持只读 |
| 目录权限拒绝/遍历不完整 | 报partial/unreadable，不能显示为空 |
| 原生prune没有冻结对象清单能力 | 锁/静止条件和范围复核；无法证明则不开执行 |
| 删除半途崩溃、恢复时同名新文件 | 记录不确定项，恢复冲突不覆盖 |

测试先在项目内 fixtures 中进行；需要验证文件身份、链接与竞态时使用隔离临时目录，不拿真实HOME验证破坏性行为。扫描性能基准需记录文件数量、大小、存储类型、权限和平台，尚不设未经测量的秒数承诺。
