# G/H/I并行执行纪律

仅适用G/H/I正式票，F原票/工作树/helper/冻结保持。每票独占自己的树/分支/目录/回执；不读他人正在实现的产品，不互相修改/提交/合并。只读辅助可用并记回执，禁止自动再分派实现worker。

主检出票面与manifest权威，执行树基线早于登记；读取主检出票面，不merge取票。先核精确基线/分支/干净、共享新锁及全部旧锁，再运行本票baseline。只改显式白名单，不改根Cargo、A–F、旧helpers/冻结、upstream、共享Vault或其它项目。

G/H只传入内存；I只冻结合成E视图和127.0.0.1临时服务/独立Chrome。无F物理fixture权限、真实用户数据、HOME/整盘扫描、普通文件内容读取、任意路径/shell、上传/清理/ACL/移动/删除。实验室marker不是通用授权。不安装包/浏览器/平台工具、不fetch或改全局配置。

每线同时一个定向门，F/G/H可各一个jobs=1离线Cargo检查，I最多一个独立Chrome；不整仓/watch/coverage或放宽时限。各树.local私有构建/日志/profile，保留现场无清理。helper是约定检查而非OS沙箱。

真实行为先红，三有效负控及原字节恢复/mtime/hash按票面。实现提交干净后本票全部final门同SHA；后加报告仅证据/文档，不夹未复测产品。原始日志和截图按字节归档，显式git add（.log需-f点名），禁批量add、reset/clean/stash、push/merge/rebase/发布。缺身份仅单命令Water Worker (external)/water-worker@localhost，不改global。

回执写受测SHA、逐项需求、命令/退出码/receipt、全部失败、三负控与恢复、scope/能力边界、实际模型和未验证平台。完成通知第一行：`<票号> 任务已完成，任务报告在 <本票绝对报告路径>`；受阻改任务受阻、保存现场写最小补充需求。交回后停止，总控验收不由工人自行标VERIFIED。
