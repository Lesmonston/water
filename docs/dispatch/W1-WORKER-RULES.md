# 第一轮外贴执行纪律

适用：WATER-W1-A及其明确编号补单。总控负责此文件。用户安排执行引擎，回执写实际模型。本轮只有一个写入者，不再启动实现子代理；只读辅助需在回执申报。

## 开工与范围

- 权威票面和manifest位于主检出 `F:/new/smaltalk/water/docs/dispatch/`；只读即可，不把main合入工作树取票。本工作树可能基于“架构冻结提交”，其STATUS比权威票面旧，以本票明确阶段为准。
- 只在本票分配工作树/分支写文件，先跑baseline核对完整SHA、分支、洁净状态、冻结哈希和Rust链接探针。initial baseline必须HEAD精确等于baseCommit；后续检查要求包含该基线。
- main和其他工作树只读。禁止改架构、契约、Schema、示例、conformance、freeze锁和总控检查脚本；需要改动写受阻回执，由总控修票。
- 只改本票明确列出的文件/前缀。禁止清理源码、缓存、用户HOME、整盘或临时清空目录；禁止通用递归删除、git clean、hard reset、全树还原、stash和批量git add。

## 开发与依赖

- 本票唯一允许创建Rust workspace、锁定指定serde依赖和下载它们的依赖。本地Cargo状态/target由helper放在本工作树`.local`，不要调用裸cargo改写默认缓存或修改全局PATH/默认工具链。
- 唯一允许的网络下载是Cargo为固定依赖访问官方crates.io/index.crates.io/static.crates.io及其正常分发端点；不复制现有配置里的密钥，不另配代理/私有registry，不调用模型、云资源、上游安装脚本或其他服务。
- 已有Rust 1.95.0、rustfmt/clippy、MSVC可用；禁止自动安装/升级Rust或Visual Studio。失效时受阻报告，不自行修全局环境。
- 没有扫描/删除/UI/服务实现权限；严禁复制research/upstream源码、规则、文案或运行其脚本。

## 检查、负控与证据

- 仅使用票面给出的真实helper与固定模式；清单只有一个crate/集成测试目标。无watch、coverage、全仓检查或同树多进程门。helper是辅助校验，不是安全沙箱，仍要遵守票面。
- baseline工具链通过不等于Rust合同测试通过；先记录目标测试的行为失败，再实现。缺文件/编译失败可记录工程过程，但不算有效行为先红。
- `test`模式要求票面五个顶层测试函数全部存在并实际运行，0 ignored/filtered；`--final`额外要求检查前后是同一干净提交。普通开发门会如实记录脏树，不得把其结果说成提交后最终门。
- helper拒绝祖先或本地Cargo配置、清除Cargo执行覆盖环境、检查依赖源、拒绝本地状态路径的链接，并在命令后复核范围/冻结文件。它不是OS沙箱；执行者仍不得借构建/测试进行票外读写或网络操作。
- 安全负控必须改真正逻辑，不植入测试开关或假执行路径；记录目标断言失败和原字节/哈希恢复。仅恢复自己当次施刀的显式文件，不用git checkout全树。
- 一个检查若仅因临时网络/负载超时失败，可不改代码原样重试一次，记录两次；再次失败或非超时问题不能改helper/超时掩盖，报告总控。
- 日志进入`.local/checks/WATER-W1-A/`；选定证据复制到本票授权的docs/acceptance目录，回执引用相对路径和测试时SHA。禁止日志输出凭证和环境变量全表。

## 提交与停止

- 只提交本分支显式文件，提交前核对staged文件清单和diff --check；不要提交.local或他人的改动。
- 实现完成提交后再跑完整定向最终门，之后可另交只含报告/证据的收尾提交；不能夹带未验证产品代码。报告写完整实现SHA、检查结果与实际未验证项。
- 完成或受阻都在指定REPORT写明事实。对话第一句与报告第一行相同：`WATER-W1-A 任务已完成，任务报告在 <实际绝对路径>`，受阻改成“任务受阻”。报告之后停止修改，不能自行标总控验收通过。
- 禁止push、merge、rebase、cherry-pick他人分支、部署或签名/付费操作。受阻保留现场，不问用户放宽文件范围，不由另一执行者接管脏树。
