# 第三波：桌面接线（W3）

2026-10-26，总控（Claude）。第二波 A–E 已全部验收并合入主线。本波把它们接成能在本机运行的桌面程序，目标是 M1 体检 Alpha：用户打开 Water，在应用里完成整机体检并看结果。登记见 [manifest](manifest.json)。

## 拆分

| 票 | 交付 | 目录 | SPEC | 门 | 窗口 | 真实数据 |
|---|---|---|---|---|---|---|
| WATER-W3-F1 服务核心 | 把 A–D 接成 IPC v1 的 17 个命令：扫描、视图、趋势、记录、位置、清理计划与执行、本地存储 | `packages/water-service` | [SERVICE](../../../contracts/desktop-v1/SERVICE.md) | **重，3 条负控**（它驱动删除） | 0 | 只读：经服务完成一次本机整机扫描，清理保持关闭 |
| WATER-W3-F2 桌面宿主 | Tauri 窗口、Mica、安全边界、17 个命令转发、数据目录、文件夹选择框接线点 | `apps/water/host` | [HOST](../../../contracts/desktop-v1/HOST.md) | 轻，2 条负控 + 1 次原生窗口 | 1 | 无 |
| WATER-W3-F3 接线与整机验收 | 宿主接上服务核心与选择框；本机整机体检 | `apps/water/host` 的 main 与新测试 | F1、F2 验收后再冻结 | — | — | 只读 |

- F1 与 F2 **可以同时做**。两者只在 JSON 层对接：宿主的 `Backend::call(command, args)` 与服务的 `Service::call(command, args)` 形状相同。F1 不依赖 Tauri，F2 本票用“服务未接入”占位后端。
- F3 在 F1、F2 都验收后才出。它只写十几行接线（宿主用服务核心实现 `Backend`，用宿主的选择框实现服务的 `FolderPicker`），然后做整机验收。整机验收的窗口预算到时另定。

## 本波的两个产品决定

1. **这一版只做体检，清理功能先不开放。** F1 完整实现并测试清理（只在合成夹具上删），但宿主以 `clean_enabled = false` 启动；用户点“清理所选”会看到“这一版只做体检，清理功能会在下一版开放。”。
   - 这与路线图一致：M1 是体检 Alpha，M2 才开放清理。
   - 第二波验收留下的 D 加固项（按句柄相对删除、不删云文件占位符、拒绝 8.3 短名）完成并验收后，再打开清理，并做自清理里程碑。
2. **窗口保留 Windows 11 系统标题栏，加 Mica。** 已验收的界面没有画窗口按钮，IPC 也没有窗口命令，所以设计稿“无系统标题栏”本波不做。要做就另出界面补单（加窗口按钮）与宿主补单（开对应权限）。

## 依赖与环境

- F1：只用 serde、serde_json 与四个已验收 crate 的路径依赖，离线缓存同第二波。
- F2：Tauri 2.12.5 与 tauri-build 2.7.4，**锁文件里每个包都必须是第一波 AC 已验收锁里的同版本同校验和**；离线构建用 AC 已下载的缓存与镜像契约的参数，不再下载。Mica 用 Tauri 自带的窗口效果，`window-vibrancy` 已在 AC 依赖树里。
- 检查入口：新脚本 `scripts/desktop-wave-check.mjs`（结构同第二波，多了 host 类任务、镜像参数、锁比对、配置与权限比对、原生窗口模式）。原生窗口观察器 `scripts/acceptance/w3-host-native-observe.ps1`：只看本进程窗口，核对页面文字、Mica 背景类型，截本窗口一张图，关窗后核对子进程结束，命令行只在内存里比对、不落盘。

## 预算与边界

- F1：原生窗口 0、选择框 0、浏览器 0；删除只在本树夹具里。真实冒烟只读，清理关闭。
- F2：测试中窗口 0、选择框 0；原生窗口检查整票 1 次，失败不自动重跑。
- 全部离线、jobs 1、私有 Cargo home/target/tmp；不改网络与全局配置。

## 总控验收计划

1. 收单核对：分支、基点、范围、负控记录、回执与证据原字节（沿用第二波的审计脚本思路）。
2. 新私有树离线重跑 check/test，总控自己做负控。
3. F1：
   - 总控在自己的合成夹具上独立跑一遍扫描与清理（清理打开），核对只删计划内条目；
   - 真实冒烟的分类体量与第二波 B 的真实结果同量级。
4. F2：逐张看原生窗口截图，确认 Mica 与界面完整；核对锁文件与 AC 锁一致。
5. 两票都通过后合入主线，出 F3。
