# W1-E 执行纪律

E只实现独立Rust内存展示库；不获得D的物理fixture权限。用户外贴后在唯一e树/分支/精确基线开工，主检出manifest与正式票为权威，不merge主线取票。

范围只含本包Cargo.toml/Cargo.lock/README.md、src/、唯一tests/view_v1.rs、本票回执与e证据。根Cargo/锁/工具链、A/B/C/D产品、contracts、控制脚本与证据.gitattributes均只读。不改全局配置或安装工具；无网络下载、裸cargo、清理、重置、push/发布。

只运行票面report-view-check的baseline/lock/fmt/test/clippy/metadata/bridge；Cargo jobs=1、180秒，一次一个检查。包依赖用本项目既有缓存离线解析。测试清单精确五个非空顶层测试；bridge必须运行实际投影库与C纯模型，不替代为fixture输出。helper检查策略，不是OS沙箱。

行为先红和三有效负控均编译成功后命中目标断言；逐文件原字节恢复、核三哈希，不全树还原。实现提交干净后串行跑所有final门，再以纯报告/证据提交归档，绑定实际受测完整SHA，记录所有失败与实际模型。macOS未跑如实保留。

不读取真实用户数据、上游、HOME或其他项目；不创建扫描/分类/清理入口，不修改C演示或声称Tauri已接通。内部辅助若使用只读且回执记录，不再分包给实现者。工单冲突原地保留现场并交受阻回执，不自己扩大范围。
