# P/Q外贴执行纪律

每对话一票，用户外贴后在指定独立树/分支执行，不再分包实现。主检出权威票/manifest、ADR-011、对应SPEC与scope-export COMMON/TESTS优先；基线早于票面，不能merge主线取票。先核精确HEAD/干净/冻结/输出目录不存在，不符受阻回执并保留现场。

只改票面产品目录、自己的回执和新证据；旧A–O/原树/冻结/helper/根Cargo/上游/台账只读。P只有本树冻结空目录/junction的元数据权限，不从JSON或外部UI恢复能力，不冒充真实用户确认。Q只有内存报告，无物理fixture/文件下载/真实扫描权限，不说匿名或可公开。没有提权/安装/fetch/清理/删除/ACL/移动/真实HOME/盘根/用户数据动作。

全部五测试/五final、行为红与三个负控按COMMON串行执行，离线jobs1、180秒子命令。真实改坏源码后必须完整五红、原字节恢复、完整五绿，记录三哈希；编译/缺文件/超时不算有效红。源/测试变化须重录受影响证据链，不改helper/弱化测试/开后门。证据目录的预置.gitattributes冻结不改，日志原字节归档。

实现提交后同一干净SHA五final，再只追加报告/证据；显式文件名add，log用-f，无reset/clean/批量add/合主线/push。报告写实际模型、完整受测SHA、需求逐项、全部失败/负控/原日志与未验证限制。完成通知只使票进入SUBMITTED，由总控验收集成。停工等待收单，不继续改交付。
