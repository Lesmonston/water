## 1. 要做的（全部在 `packages/junk-scan/`）

### 1.1 接口（补充 01 第 1.1 节，照抄，不增不减）

- 新增 `pub struct RootProgress { root, roots_done, roots_total, visited_entries }`，派生 `Debug, Clone, PartialEq, Eq, Serialize, Deserialize`，从 `lib.rs` 导出。
- `ScanObserver` 加 `fn on_root_done(&self, _root: &RootProgress) {}`，带空的默认实现。
- `ScanProgress` 与 `on_progress` 的时机、次数都不变。

### 1.2 什么时候报（补充 01 第 1.2 节）

- 根目录：`Pattern` 的 `base`、`Marker` / `Discovery` 的 `root`；兜底 `Marker`（`fallback_for` 有值）不算；照扫描现有的做法不分大小写去重。`roots_total` 是去重后的个数。
- 每个根目录恰好报一次，`roots_done` 从 1 数到 `roots_total`：
  - 一开始就不走的（`ignored_root`，或在 git 工作区里）：开始走之前按计划顺序先报；
  - 走到时跳过的（不存在、不是目录、是重解析点、已经在更早的根目录里走过）：走到它时报；
  - 实际走了的：它的子树全部走完（栈空）之后报。
- `root` 用计划里第一个用到这个根目录的目标写的原样字符串；`visited_entries` 是报的那一刻 `Engine` 的计数。
- 取消或预算用完整趟提前结束时，还没轮到的不报。`space_overview` 不报。
- 提示：现在根目录的收集只放进了会走的那些（第 349 行一带先跳过了 `ignored_root` 与 git 工作区里的）。`roots_total` 要把这些也算上，并在走之前报掉。
