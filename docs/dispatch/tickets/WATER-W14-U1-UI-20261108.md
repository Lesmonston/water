## 1. 要做的（全部在 `apps/water/ui/`）

### 1.1 字符串表与语言切换（W14 第 1.1、6.1 节）

- 新建一张字符串表，中英两种，键完全一致。界面自己的所有文字都从这里取，包括：
  - 按钮、标题、提示、对话框、空状态；
  - `aria-label`、`title`、`placeholder`；
  - 关于页的几段说明；
  - `app.mjs` 里的兜底错误与导航名；
  - `model.mjs` 与各视图里的小表。
- 取文字统一走一个函数（例如 `t(key, params)`）。视图里不再直接写中文。
- 设置页加“语言 / Language”，三个选项：`跟随系统`、`中文`、`English`。
  - 存在 `localStorage` 的 `flick.language.v1`，读写都包 try/catch，读不到就当 `system`。
  - 切换立即重画，不重启，不重新体检。
- `system` 的解析照 W14 第 1.1 节：
  - 先看 `app_info.system_language`；
  - 空或没有这个键时看 `navigator.language`；
  - 以 `zh` 开头用中文，其余用英文。
- `index.html` 的 `lang` 与标题随语言变。

### 1.2 服务文字与格式（W14 第 1.3、6.1 节）

- **取服务文字**：
  - 英文时取 `<名字>_en`，没有这个键就退回 `<名字>_zh`；
  - 线索复制取 `copy_text_en` / `copy_text`；
  - 错误取 `message_en` / `message_zh`。
- **格式化两种**，照 W14 第 0.2 节：
  - 日期、相对时间（顺手改成按本地时间算，现在 `relativeTime` 用的是 UTC）、“约”、列举、`F 盘` / `Drive F:`、“N 天”一类；
  - `format.mjs` 与视图里拼字的地方都改。
- **英文词汇**只用 W14 第 7 节的表。表里没有的，回执列出你用的译法。

### 1.3 主页面一屏放下（W14 第 6.2 节）

- 这些页面在 1240×820 与 1040×720 下，中英都不出现页面级的纵向滚动：
  - 首页、体检中、结论、清理确认、清理中、清理完成、隔离区、趋势、记录、设置。
- 长列表只在卡片内部、抽屉或详情页里滚动。
- 做法：
  - 收紧留白与卡片高度；
  - 去掉多余的说明（第 1.4 节）；
  - 必要时把次要信息收进卡片内部滚动或“⋯”菜单。
- 正文字号不低于 13px，不缩放整页。
- 视觉照现有 v3 风格：白色磨砂玻璃、实色强调色、不用渐变、不用表情；只用现有的设计 token。

### 1.4 文案收拾（W14 第 6.3 节）

- 逐页去掉只是在描述图表或重复显而易见的说明。至少：
  - 体检中的“每秒一根 · 本次体检”“按已检查的文件估算”；
  - 各图表上类似的副标题。
- 每页保留的说明不超过一行，必须说一件看图看不出来的事。
- 回执列出删掉与改写的每一条（原文 → 新文或删除），中英都列。

### 1.5 体检中这一页（W14 第 6.4 节）

- **进度**：
  - 主数字取 `percent`；
  - 状态文字照服务的阶段：
    - `running` 时“正在体检” / `Checking`；
    - 有位置在 `space` 时“正在统计整盘空间” / `Measuring the whole drive`；
    - `finishing` 时“正在整理结论” / `Putting the results together`。
- **位置卡片**：
  - 照 `locations[].state` 显示等待、扫描中、统计整盘空间、完成；
  - 不再出现“完成”而整体还在走的情况；`space` 显示为进行中，不是完成。
- **完成后的下一步**：
  - 最终状态照旧自动转到结论页；
  - `cancelled` 也转到结论页，并在页面上说明“已停止，下面是停之前查到的” / `Stopped. Here is what was found before that.`；
  - 不停在一个没有按钮的页面。
- **方块图**：
  - “发现的可清空间”这张卡用方块图替换竖线图（`stems` 不再用于这一页）；
  - 每个类别一块，面积按 `categories[].found_bytes`，随轮询长大；
  - 类别名与大小放在方块上或悬停提示里，不加副标题；
  - 颜色沿用结论页现有方块图的样式（v3 定稿的天蓝深浅，`--sky-1`～`--sky-4`），相邻类别用不同深浅区分，不用渐变；
  - **不改 `styles/tokens.css`**：它必须与 `docs/design/water-ui-v3/tokens.css` 逐字节一致，检查器会核对。需要的样式写在 `styles/app.css` 里，只引用现有 token。
- 每秒取样的 `scanSamples` 不再需要的话一并去掉。

### 1.6 跳过之前准备的计划（W14 第 6.5 节）

- 确认清理时 `clean_start` 返回 `stale`：
  - 先重读结论（`conclusion_get`）；
  - 结论没有过期：重新准备计划（照现有的准备流程），回到确认页，提示“跳过名单变了，已按新的结论重新准备” / `The skip list changed, so the plan was prepared again`；
  - 结论确实过期，才显示“结果已过期 · 重新体检”。
