### 1.2 0 字节写 0（收口报告 R7）

- 现状：`format.mjs` 第 10 行把 0 也写成 `<1 MB`，于是“你选的”是 0 时显示“<1 MB”，空隔离区的总量也是。
- 要求：`formatBytes` 遇到 0 返回 `0 MB`；`byteDelta('0')` 也是 `0 MB`（不带加号）。1～1,048,575 字节仍是 `<1 MB`，负数与别的取整不变。

### 1.3 结论页写“部分完成”（收口报告 R9）

- 现状：整盘体检常因有的位置没有权限、或到了时间上限而是“部分完成”（结论里 `status` 为 `partial`），结论页不提。
- 要求：结论页页头的小字（`views/results.mjs` 第 7 行 `heading` 的第二个参数）在 `status === 'partial'` 时末尾加 ` · 部分完成：有的位置没有权限，或时间到了`。别的状态不加。别的页不变。
