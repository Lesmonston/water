## 2. 第十四波共同的

- **契约第 0 节**：公开前的写法、英文的写法、测试的规矩。
- **词汇表**（契约第 7 节）：英文的专有名词只用表里的译法。表里没有的，回执里列出你用的译法，由总控统一。
- **三份共享样例** `contracts/*/ui-fixtures*.json` 本波谁都不改。
- **旧断言**：工单预列了“获准修改”的，照预列迁移；没预列但因本单必然要变的，照通用规则第 3 节第 1 条直接迁移，不得变弱。回执逐条写原值 → 新值 → 为什么。
- **测试个数不变**：新断言加在已有测试函数里。
- **依赖**：不改任何 `Cargo.toml` 的依赖与 `Cargo.lock`，不改 `package.json`。
- **系统函数**：不新增，照各包现有的。
- **计时**：不加新的墙钟时限断言。只因计时失败的照通用规则第 3 节第 2 条处理。

- 同一时间机器上可能有三张单在编译与测试。跑 cargo 前按进程名看一眼；别的单在跑测试时，计时类断言偶尔会超，照通用规则第 3 节第 2 条重跑。
