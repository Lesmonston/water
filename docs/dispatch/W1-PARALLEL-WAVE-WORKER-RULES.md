# S/T/U外贴执行纪律

每执行对话只一票，在本票独立树/分支和白名单实现；直接读主检出正式票/manifest，不merge取票。R及其它树不碰；所有旧产品/根Cargo/冻结/helper/台账/上游只读。总控独占集成/验收，执行者不再分包实现、不push。

首次核精确HEAD/分支/干净/冻结/产品不存在并只跑本票baseline；不符保留现场交受阻回执，不重置。baseline只验证已验收依赖/工具/输入，不代表新五测。模式/红绿/全部final/资源/证据按parallel-wave COMMON及SPEC，不改工具或放宽测试。日志原字节保存，所有失败如实记录。

S只有受控本树native dialog/P登记，测试用冻结driver，不能操作其他进程窗口或真实目录；T只有内存报告/固定loopback/浏览器本树下载；U只有内存清单文本。不得跨票读取真实数据或运行未知脚本。任何接口/依赖/权限冲突写受阻回执交总控修订，不问用户临时放宽范围。

完成后报告绑定同一干净受测实现SHA，再只加报告与证据。显式文件名add（log用-f），无clean/reset/批量add/merge/push；通知只使票SUBMITTED，不能自行VERIFIED，交回后停止修改。
