## 1. 整组、整行“以后都跳过”

| 在哪点 | 记下什么 | 以后怎样 |
|---|---|---|
| 判断卡“⋯ → 以后都跳过” | 这张卡的组（组 ID 带“位置 + 规则”，如 `custom:drive-d:python-tool-caches`；泄漏簇是 `leak:` 加父目录与模板的哈希） | 这个组里的可清项都判为“已设为以后都跳过”，新长出来的也算 |
| 合并卡 | 卡里每个位置的组，一次全记 | 同上 |
| 抽屉的“同模板”一行 | 组 + 模板 | 符合这个模板的都跳过 |
| 抽屉的“同一父目录”一行 | 组 + 父目录 | 这个目录下的都跳过 |
| 抽屉的“其它 N 项” | 不提供 | — |
| 单个条目（现有） | 路径 | 不变 |

- **依据**：第八、九两次真实复验的扫描记录相隔 6 小时、版本不同，48 个组 ID 全部相同，4 个泄漏簇也相同。
- 一次点击原子、64 条上限不变、绑定结论版本、立刻生效、跳过名单写清是什么。精确规则见契约 [W12](../../../contracts/w12-v1/W12.md) 第 1 节。
