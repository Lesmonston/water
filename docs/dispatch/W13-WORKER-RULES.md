## 2. 第十三波共同的

- **公开前的写法**：照契约第 0 节。本波改到或新写的代码、注释、测试、测试数据、README，都不写本机用户名、本机路径、本机项目名、私人邮箱、私有流程的引用（验收、派单、交接的文档路径，工单号，“总控”）。各单顺手清理自己目录里已有的这类内容（工单列了位置）。回执里同样不要贴本机路径以外的私人信息。
- **旧断言**：工单预列了“获准修改”的，照预列迁移；没预列但因本单必然要变的，照通用规则第 3 节第 1 条直接迁移，不得变弱，回执逐条写原值 → 新值 → 为什么。
- **测试个数不变**：新断言加在已有测试函数里。
- **依赖**：不改任何 `Cargo.toml` 的依赖与 `Cargo.lock`，不改 `package.json`。
- **系统函数**：不新增，照各包现有的。
- **计时**：不加新的墙钟时限断言。只因计时失败的照通用规则第 3 节第 2 条处理。
