# M3.5 基准表：每一轮清理的每一项，Water 应当怎么认

2026-11-02，总控（Claude）。第十波 M3.5 验收的依据（[第十波计划](PLAN.md)第 5 节第 2 条、[第九波计划](../wave9/PLAN.md) 4.7 节）。逐项写明 Water 第十波之后应当给出的级别与处理；做不到的写明为什么不归 Water 管。

**级别**：
- 推 = 推荐清理（默认清）；
- 判 = 需要确认（判断卡或明细里的“需要确认”）；
- 参 = 仅供参考；
- 护 = 受保护；
- 跳 = 照常列出，但这次跳过，并写出解除条件；
- 建 = 系统建议（只给怎么做）；
- 布 = 只出现在空间分布里；
- 外 = 不归 Water（资料、游戏、在用的依赖，或要读内容才能判断）。

**行号**指[第十波计划](PLAN.md)第 2 节的行。验收时：
1. 用合成夹具（按本表的名字、层级、大小分布造结构，不放真实内容）跑真实服务，逐行核对；
2. 最后在本机真实数据上只读体检一次，核对仍然存在的项。
