  edition, rust-version and dependency versions from the root workspace, so every
  crate that depends on it failed `cargo metadata` without them.
- water-service tests use the checkout's drive instead of a fixed F:.

  that read the same clock value no longer collide.
- skip_unit_add writes settings synchronously, so its test return budget is 200 ms
  like skip_add.
- actions/checkout v4 -> v5 (Node 20 is deprecated on GitHub's runners).
