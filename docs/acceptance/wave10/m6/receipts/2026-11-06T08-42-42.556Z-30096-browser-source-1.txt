# Water WebView UI · M3.5 / design v3

原生 ES 模块，无 npm 或运行时依赖。由可信宿主提供 36 个 IPC 命令；无内置回放数据。开发测试中的假宿主只位于 tests/browser.test.mjs。

- app.mjs 管理路由、命令、轮询和模态焦点。服务返回整份结论后替换当前视图；不在界面计算清理计划。
- ipc.mjs 是宿主边界，保留原 19 个命令并添加 IPC-M35 的 17 个命令，校验精确形状、ID、决定和搜索词。
- model.mjs 包含显示规则；旧格式测试所需的曲线纯函数保留。
- views/ 按页渲染；charts.mjs 只把服务给的数据换算成图形位置和比例。styles/tokens.css 是 v3 原样令牌。
- 菜单与浮层支持键盘。清理和永久删除期间关闭窗口会提示；空闲不轮询，连接失败可重新连接。

首页选择本次位置，新增文件夹单独选中。结论页保留服务顺序与全部判断卡。补单 02：只有真实条目 ID 可以永久跳过；卡片忽略 skip，合并汇总行仅允许展开。重复文件清理只进入隔离区。

设计稿的数字是样例。没有数据的统计不补算：没有历史累计释放数、按月合计、类别历史体量或清理后的预测日期。图中历史点只使用已有记录，体检竖线仅记录当次收到的进度采样。抽屉底部显示服务给出的整体计划，不自行计算当前组已选体量。

检查从票面工作树根目录通过项目的 checkup-wave-check.mjs 运行。unit 精确 3 项、browser 精确 6 项；截图输出到检查器指定的本树 .local 目录，再由 archive 归档。Windows 私有 headless 浏览器测试使用合成 IPC 样例，不调用原生文件夹选择框、打开真实目录或删除真实数据。真实服务联合接线与 macOS 不属于本票验证。
