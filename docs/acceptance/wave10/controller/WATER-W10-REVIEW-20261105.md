## 4. 独立审查

只读代理只拿契约、单子与代码，不看回执。两张都**没有高危**。较低的发现都记入第十波清单各单的 `carryOverLater`，要点：

- **M3，交给 M7 的两条**：
  - `protects` 只认 `X:\` 写法，`\\?\`、UNC 与带 `:` 的段一律返回 None；M7 调用前要统一成 `X:\` 写法。
  - 路径是声明目录的**上级**时，按契约不算重叠；M7 仍要保证清理条目不会包住声明目录（例如把它的保护路径放进清理计划的 `protected_paths`）。
- **M3，其余**：
  - 同一份声明有多个问题时，报出的第一个不是按文件里的顺序（未知键按字母序）；
  - 真实冒烟用 `ancestors().nth(4)` 找仓库根，只在 `.worktrees/<名>/` 下可用，下次动这个包时修；
  - 路径里的控制字符报 `MANIFEST_FIELD` 而不是 `MANIFEST_PATH`；
  - 几处只测了拒收一侧的边界。
- **M9**：
  - 中日韩文字与字母、数字连在一起时算一个词（`腾讯QQ`），按契约字面如此，M7 不能只凭这一点说“似乎已卸载”；
  - `collected_at` 是 Unix 秒数字符串，M7、IPC 要换成其它契约用的 RFC 3339；
  - 超长值在去空白前就被丢掉；5000 条上限按枚举顺序截断；
  - 登记类型映射、上限与 `unreadable_keys` 没有测试。
