## 3. 各票

### A 规则登记表

- 60 条种子规则与 RULES 第 5 节逐行一致（级别、分类、定位器、年龄、保留数、在用、增长），校验器拒绝未知键与越界，错误不回显输入。浏览器可清理规则只碰缓存目录，碰不到 Cookies、登录数据、Local Storage、IndexedDB、Session Storage。
- **保护优先判定被放宽（高）。** RULES 第 3 节写“任一段含通配符视为可能重叠”，执行者改成“只有可清理一侧带通配符才算”。这样一条 recommended 规则写成 `User Data\Default` 或 `User Data\Default\Network` 也能通过校验，而它会整个包住 Cookies 与登录数据。
- **根源是总控契约写错。** 按契约原文，种子集自己就过不了：三个浏览器 `User Data` 根下的 ShaderCache、GrShaderCache、GraphiteDawnCache 共 9 个定位器，都会被判为与 `User Data\*\Cookies` 重叠。执行者遇到契约冲突应按执行者规则第 2 节交回受阻，而不是自行改判定，并且回执写了“无阻塞”。本次记一笔流程问题。
- 运行期仍有 B 扫描时的 `contains_protected` / `inside_protected` 兜底，所以当前没有真实风险，但校验器这一层必须补上。
- 补单 A-01：受保护的浏览器定位器改为显式列出配置目录（`Default`、`Profile *`、`Guest Profile`、`System Profile`），重叠判定改为“通配段与字面段按 glob 匹配，两侧都含通配符视为重叠”。这比原契约与执行者的实现都严。测试补齐错误码断言与进程名核对。
- 真实冒烟：60 条中 56 条已知目录存在、45 条字面前缀存在。未命中的 Brave、Firefox、uv、Ollama、Hugging Face 等与摸底一致（本机未装或未用）。

### B 扫描引擎

- 重解析点处理扎实：路径中间段遇联接不进入并记 issue；条目内的联接只计 0 字节、不进入。名字归一化 7 个样例全对，`claude` 这类普通词不被吞。
- 真实交叉核对：与摸底同口径的 4 处，npm 缓存 2.1744 GiB（摸底 2.174）、崩溃转储 0.3249（0.325）、Codex 插件暂存 3.5652（3.565）、Claude Code 会话 6.4525（6.439，增长 +0.2%），均在 2% 以内。系统临时目录口径受下面的缺陷影响，补单后重测。
- **高：discovery 排除方向写反。** SPEC 要求排除“是其它条目祖先”的子项，代码排除的是“在其它条目之内”的子项。后果：`C:\Windows\Temp\claude` 被当成 system-temp-old 的一项（推荐级、7 天），而它里面是需要确认级（72 小时）的 Claude Code 临时目录，满 7 天后会按推荐级被清，绕过确认级；同一批字节还被计了两次（约 1.1 GB）。
- **高：非 ASCII 路径会让整次扫描崩溃。** `util.rs` 按字节下标切 `&str` 做前缀比较，遇到中文等多字节名字切在字符中间就 panic。本机临时目录里出现中文名的概率很高。
- **中高：预算用尽或取消后，仓库守卫失效。** 停止后列目录返回空，`.git` 检查跟着失效，partial 结果里含 `.git` 的目录可能被判为可清理；`budget_exhausted` 还会被重复累计。
- 中：不带花括号的 GUID 没有归一化。低：日均增长用四舍五入后的天数做除数，短间隔时低估。
- 总控第一条负控（把目录联接归为普通目录）被测试抓住了，但抓住它的断言没带 `SCAN_NO_FOLLOW` 标记；第二条负控（体量遍历进入联接）按标记通过。补单要求所有不跟随断言都带标记。

### C 进程与在用

- 隐私达标：命令行只在内存，`ProcessSnapshot` 无 Serialize，Debug 不含命令行，错误是固定文案，真实冒烟只出计数。FFI 只用允许的调用，句柄全部按 RAII 关闭。
- **测试清理可能误杀无关进程（严重，测试代码）。** `stop()` 收集本次令牌命中的进程，再加上孤儿链的全部后代 PID，然后逐个 `taskkill /F /T /PID`，下手前不再复核。后代里有不带令牌的 `ping.exe`；更糟的是 PID 被 Windows 复用时会连同整棵进程树结束别人的进程。在补单修好之前，总控不再运行 C 的测试。
- **主要：后代 PID 没处理复用。** 子表只按父 PID 建，查孤儿根时考虑了复用，找后代时没有，早于父进程创建的无关进程会被算成后代。
- 中：路径匹配失败后按 1 字节前进，路径首字符为多字节时会在字符中间切片 panic，panic 信息会带出命令行片段。公开 API 可达，合法盘符路径不会触发。
- 真实冒烟：384 个进程、5 个无权限、7 个已退出，Chrome 14、Edge 12、Node 5，默认模式孤儿 0，与本机实际量级相符。

## 4. 本次总控决定

1. **浏览器“网站离线数据”（Service Worker CacheStorage）保持“需要确认”、默认不选。** 用户定的边界是“不清登录认证信息，避免清理后重新登录”，这类缓存不含登录状态，清掉不会掉登录，所以可以由用户自己确认后清理。Cookies、登录数据、本地存储、IndexedDB、会话存储始终受保护。关于页与规则说明按这个口径写清。
2. **契约订正走补单覆盖条款，冻结契约文件本身不改**，与 E 补单 01 的做法一致，执行树里的冻结指纹不受影响。
3. **补单都在原树原分支续做**，不重跑 baseline，所有 final 与负控按新字节重做。
