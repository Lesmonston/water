# F worker source review

Scope: the implementation in `packages/fixture-scan`, Windows Rust 1.95. Reviewed by this execution agent; this is not the controller's independent acceptance. No helper, frozen contract, old product, root Cargo file or upstream source was changed.

| Boundary | Source review result | Runtime evidence and limit |
|---|---|---|
| Private capability | FixtureRun/ScanNodePath have private absolute paths and guards; neither has a constructor taking caller paths, Deserialize, Default or an absolute getter. Debug emits only run/case or relative identifiers. | Six tests check public open/scan behavior and Debug output. Adapter code is trusted Rust code, not UI-supplied behavior. |
| Fixed root | `marker.rs` derives the tree from CARGO_MANIFEST_DIR; run-id bytes are fully validated before path IO. `native::directories` starts at the filesystem root and checks every component with symlink_metadata, without enumeration. Direct-child containment is checked after the no-follow guard. | Six controlled marker/root negatives and all frozen invalid IDs/options are rejected. No real user directory was used as a fixture. |
| Strict original marker | `Marker` and every nested object deny unknown fields; struct deserialization detects duplicate keys directly in the original JSON. String fields reject non-string enums/versions. Required nullable fields use deserialize_with. Scope/node/canary order, plan and case identity are compared to embedded D definitions; status/error-code combinations and canary number/hash shape are checked. | Physical negatives cover duplicate, oversized, missing and traversal markers. Not every nested malformed-marker variant has a separate physical fixture in this ticket; the remaining field rules were source reviewed. |
| Content reads | The sole production File::open is the checked marker path. The pre-read length check is followed by `take(LIMIT + 1)` and an actual byte-count check. NativeIo has no payload open/read, read_link, fs::metadata or canonicalize. Frozen case content is compile-time input, not a file payload read during scanning. | IO trace verifies only inspect/list_names operations. The frozen helper independently verifies 44 content/marker snapshots; hash equality alone does not prove absence of reads. |
| Native no-follow | Inspect classifies all Windows reparse attributes as Link before ordinary file/directory handling. `list_names` independently rechecks the directory and all ancestors, so misclassification does not authorize traversal. | Native link facts plus zero target/prefix-sibling calls; negative control NC1 retains this independent guard. Windows symlink/junction/hardlink fixtures are supported on this host. |
| Native directory errors | `read_dir` creation and every per-item Result map through `fault`; no flatten/filter_map drops errors. The batch is discarded on error; the loop returns once it collects limit+1 names. | Native directory-limit behavior exercised. Injected batch errors prove propagation only; actual OS iterator failure and ACL denial are untested. |
| Runtime guards | Every NativeIo operation walks directory ancestors again and compares saved known Unix device/inode values for fixed run/scope ancestry. Missing roots, non-directories and links return RootChanged. Windows Unknown identity cannot distinguish all same-path replacements. | RootChanged propagation uses a delegating test adapter. No physical rename/delete/ACL manipulation and no adversarial race test. |
| Traversal | `walk.rs` consumes only ReadOnlyIo; marker nodes and scanner_plan do not drive entries or automatic failures. Batches are bounded and duplicate-checked before child inspection, sorted by encoded bytes, and names require one exact Normal component plus valid A relative paths. | Reversed batches, invalid/non-Unicode names, duplicate/oversized batches, exact depth/budget boundaries and overlap scopes are tested. |
| Accounting/cancellation | Visit increments happen before inspect, including failed/unrepresentable candidates. Observer runs only after facts are appended. CancelToken clones share Arc<AtomicBool>; checks precede pending operations' limits, without retroactive final cancellation. Stops preserve completed scopes and add precise issues to remaining scopes. | Pre-cancel zero IO; observer cancellation; depth/budget precedence; final-item completion; global counts and injected/native issue origins are checked. NC2–NC4 independently challenge these paths. |
| Capacity/identity | Only File has logical length. Allocated bytes stay null; no reclaim/aggregation/classification fields exist. Hardlinks and overlaps remain distinct paths. Windows identity is Unknown; macOS uses safe stable dev/ino/nlink and inode-zero fallback. | Windows tests and actual Rust bridge. macOS source is cfg-isolated but was not compiled or executed here. |

No unsafe code, process/network call, filesystem write/delete/move/ACL operation, production environment override, UI/IPC/export or ScanReport assembly exists in the package. These source observations and bounded synthetic tests do not establish a production filesystem security guarantee.
