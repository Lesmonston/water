# Water 桌面界面

WATER-W2-E / 补单 01、02 的原生 ES 模块前端。没有 npm、框架、运行时依赖或内置演示数据。

## 结构

- `index.html`：页面骨架与设计稿图标 sprite；只引用两份样式与入口模块。
- `styles/tokens.css`：设计方原文件的逐字节副本；`.gitattributes` 保留字节。
- `styles/app.css`：白色磨砂组件、键盘焦点、两种窗口尺寸、减少动画模式。
- `app.mjs`：六个 hash 路由、会话内状态、串行 IPC 操作、250ms 进度轮询、焦点恢复。
- `ipc.mjs`：唯一宿主调用边界，导出 IPC 契约的 17 个命令函数；参数按命令显式构造，拒绝路径。
- `format.mjs` / `model.mjs`：BigInt 字节格式化、相对时间、选择及合计纯函数。
- `views/`：首页、扫描、结果、详情、确认、清理、完成、趋势、记录、位置、隐私各自独立模块与共享 DOM 构建函数。
- `tests/unit.test.mjs` / `tests/browser.test.mjs`：精确三项单测与四项浏览器测试；假宿主与回放数据仅由测试加载。

## 运行与验证

下一波可信桌面宿主加载 `index.html` 并实现 `contracts/checkup-v1/IPC.md`。普通浏览器没有宿主时显示“无法连接 Water 服务”；不会自行扫描文件、执行删除或填入模拟数字。仅记忆上次页面，其余状态不持久化。

从本票工作树根目录运行：

```powershell
node F:/new/smaltalk/water/scripts/checkup-wave-check.mjs --task WATER-W2-E --mode check
node F:/new/smaltalk/water/scripts/checkup-wave-check.mjs --task WATER-W2-E --mode test
node F:/new/smaltalk/water/scripts/checkup-wave-check.mjs --task WATER-W2-E --mode browser
```

浏览器测试只服务本 UI 的静态文件，使用本树冻结 helper 创建一个私有无头 Chrome。测试从 `WATER_W2_SHOTS_DIR` 获取截图目录；缺失时写本树 `.local/ui-shots/<时间戳>/`，不写文档目录。final 与 archive 按票面顺序运行，由检查入口核对并归档截图。

## 行为与边界

不可选组在默认选择、直接修改、分类全选与合计四处受保护。合计使用 `eligible_bytes`；行内占用使用 `total_bytes`。新扫描安装结果时重置选择。过滤和排序不丢弃选择；部分扫描明确标注“部分结果”。

扫描与清理任务在切换页面后继续轮询，完成即停止。一次只发一个进度请求，相邻请求至少间隔 250ms。进度 busy/unavailable 连续失败最多 20 次，成功即重置计数；失败上限后保留任务状态，按钮只重新连接进度，不重新执行。清理关闭保护直到收到终态并取回结果才解除。扫描开始后的 idle 只有在见过 running 后才结束，否则最多等待 20 次并提示重试。

启动等待 app_state 时显示“正在读取…”。确认框默认聚焦“取消”，焦点锁定在框内，Esc 取消；提交时关闭确认框并丢弃令牌，失败要求重新准备。确认令牌允许不透明字符（含 /+=），只限非空、512 字符以内且无反斜杠；其它 ID 仍用原规则。清理结束刷新 app_state；正在查看记录则立即重载，回首页可体检并保留上次结果入口。旧结果仍标为过期，重新扫描前不能再次清理。

预览图仅定义视觉。页面所有数字使用宿主字节值按二进制单位格式化，例如冻结回放推荐量为 31.2 GB、实际释放量为 30.7 GB，与静态稿的 31.7 / 31.2 不同。GB/MB 都有千分位，舍入达到 1024 MB 时提升到 1.0 GB；负增长只显示一个减号，相对日期用 UTC。按体量时分类内先按级别、同级再按大小；按增长仍按增量降序。

趋势图按体检次序等距，使用限幅切线的单调三次 Hermite 曲线，淡纯色面积不渐变，保留文字记录。四种标注为首次、最低点、最低点后空间回升及今天；IPC v1 的趋势点没有清理事件字段，“清理后”按补单设计标注回升点，不能作为实际清理事件或释放量证明。详情只展示宿主提供的最多 200 项，显示范围不能冒充完整分组最早活动时间。首页与完成页共用带瓶口、轮廓及内高光的 SVG 瓶身，有上次体检时添加对应磁盘的薄荷色可释放层。

## 已知限制与待接线事项

- 本票仅交付 WebView 内前端，不包含 Tauri、原生扫描、真实清理或物理磁盘空间核验。
- 窗口顶部预留 40px 区域及拖动标记；最小化、最大化、关闭事件、Mica 和关闭时的原生清理确认由下一波桌面宿主接线。IPC v1 未定义窗口控制命令，因此本前端不新增命令或绘制无效窗口按钮。浏览器卸载仅安装标准 `beforeunload` 清理中保护，不能代替原生关闭事件处理。
- 系统剪贴板写入只发生于用户点击复制建议；失败时提供选中文字复制的提示，不读取剪贴板。
- 浏览器测试验证 Windows 上的私有 Chrome；未验证 WebView2 原生窗口、60fps 指标、macOS 或真实触屏。
- 浮层与底部坞使用背景模糊；列表卡片使用固定白色透明度和共享材质，避免逐行增加模糊层。减少动画模式关闭全部动画与过渡，键盘触发的页面与浮层切换即时响应。

动效按冻结设计的 8s/13s 水波、400ms 页面、220ms 浮层实现，并使用本地 `ui-animation` 技能检查反馈目的、transform/opacity 过渡和减少动画行为；未更改设计 token。
