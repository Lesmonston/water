## 1. 令牌（[tokens.css](tokens.css)）

- **天蓝页头**：`#AFC7E6 → #C7D9EF → #DCE7F4` 从上到下，右上与左上各一团很淡的白光。页头文字用深海军蓝 `#0F2238`，次要 `#45607F`。不用白字（浅蓝底上白字看不清）。
- **底板** `#F2F5F9`，上边两个角 30px 圆角；**卡片** 纯白，22px 圆角，极淡的两层阴影，没有描边。
- **墨色** `#14181F` / `#5B6573` / `#98A2B0` 三级文字；分隔线 `#EEF1F5`。
- **强调蓝** `#2E6FD8`：只用在选中的图标底、文字按钮、“清理”描边按钮、“最近一次”的那根竖条。
- **状态**：绿 `#2E9E66`（好、完成、不会满）、琥珀 `#D98A12`（要看一眼、快满、仍在长）、红 `#DC4A4F`（删不掉、永久删除）。每个状态都配淡底小圆徽或小胶囊，从不只靠颜色：旁边一定有字。
- **竖条**：淡绿 `#BFE5CF`，最后一根深绿 `#8FD1AC`；要注意的用淡琥珀 `#F4D49B`；没数据的灰 `#DDE3EA`。
- **字**：正文 Segoe UI Variable Text / 微软雅黑；数字 Segoe UI Variable Display 细体（300），等宽数字。页头大数字 62px，卡片数字 40 / 32px。

## 2. 骨架（每一页都一样）

窗口 1240×820 设计，从上到下：

1. **顶栏** 64px：左边冰山标志 + Water；中间导航胶囊组（选中的一项白底）；右边“只读扫描”小标与齿轮。隔离区有东西时，导航里写体量（琥珀色）。
2. **页头** 150px（列表页 132px）：左边眉题、超细大号数字或一句标题、一行说明；右边上面一排信息胶囊（如“上次体检 10 月 26 日”“Chrome 开着，会跳过约 0.4 GB”），下面主按钮或次按钮。
3. **标签排**（只在体检这一组页面）：一排高 70px 的标签，下沿压进底板 16px。选中的标签纯白、浮起；没选的是浅蓝灰；“＋ 文件夹”是虚线框。
4. **底板**：左边内容区（卡片网格），右边 340px 一个高的侧栏卡（首页“本次体检”、结论页“交给 agent”、完成页“清理前后”）。列表页（隔离区、趋势、记录、设置、查重）不要侧栏，内容铺满。

卡片统一写法：左上图标 + 标题，右上一个圆形小按钮（“⋯”菜单或“↗”打开）；下面一行小灰字标签；一个大数字（带单位与状态小圆徽）；需要时一条细竖条图或两格小数字；最下一行左右两个小注。按钮成对时等宽。

## 4. 按钮（替换 v2 第 4 节的样子，规则不变）

| 类型 | v3 的样子 |
|---|---|
| 主按钮 | 墨色实心胶囊，高 50px（页头）或 40px；带体量时体量用 70% 透明度跟在后面 |
| 次按钮 | 白底细描边胶囊；在天蓝页头上用半透明白（“停止”“去隔离区”“打开文件夹”） |
| 卡片主选 | 强调蓝描边胶囊“清理”，与“保留”等宽成对 |
| 文字按钮 | 强调蓝字（页头上用墨色），可带一个小箭头 |
| 危险 | 红字“永久删除”；确认框里选了“直接删除”时主按钮变红 |
| 圆形小按钮 | 34 / 28px 白底细描边：“⋯”菜单、“↗”打开、重新体检 |
| 标签 | 70px 高，左图标块、两行字、右边圆形勾（选中墨色实心） |
