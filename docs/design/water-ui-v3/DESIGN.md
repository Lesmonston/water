# Water 界面设计 v3（定稿）

2026-11-06，总控（Claude）。用户 11-06：“UI方面，冰山的动画先放弃，但是整体的UI需要大的重构，现在太不好看了。不简洁清爽。你先按照这种颜色基调，整体重构UI设计，以及该排版。排版你自己重新做。”参考图存在 [feedback/20261106-user-reference-palette.png](feedback/20261106-user-reference-palette.png)。所有参考图只借颜色、留白与图表的做法，不照搬它们的界面、图形或品牌。

**状态：定稿**。用户看了第五轮两屏的网页后说：“可以，定稿吧”（11-06）。总控按同样做法铺开其余九屏，结果是 [mockup.html](mockup.html) 十一屏（`?s=` 切页面，`drawer`、`confirm` 盖在结论页上），截图在 `previews/`，令牌在 [tokens.css](tokens.css)。各轮经过见第 6、7 节；第三轮原稿移到了 `round3/`，第四、五轮在 `round4/`、`round5/`。下一步改 UI-M35 的令牌来源与页面描述（第 5 节），再重出 M6 界面单。设计稿里的数字都是样例。

## 0. 改什么、不改什么

| | v2 | v3 |
|---|---|---|
| 信息结构 | 设计 v2 第 1～6 节 | **不变**：一屏一件事、三次点击清完、最多 5 张判断卡、收起的只说一句话、结论由服务算、隔离区、趋势、记录、设置、查重，都照 v2 |
| 冰山可视化 | 一直在试（viz-skeuo、viz-iceberg） | **放弃**（用户 11-06），冰山只留在标志里 |
| 导航 | 左侧栏四项 + 底部齿轮 | 顶部居中一组小圆角分段：体检 · 隔离区 · 趋势 · 记录，选中的一项黑底；右上“只读扫描”眼睛与齿轮 |
| 底色 | 近白磨砂玻璃窗 | 整窗一层浅天蓝到白的渐变；白卡片加一圈很淡的细线，几乎没有阴影 |
| 主结论 | 卡片里的超细大号数字 | 左边深色大标题（上面一行小字写范围与时间），右边三个细体大数 |
| 主按钮 | 强调蓝实心 | 每屏一张**黑色主卡**，主按钮是卡底的白色大按钮；页面别处不放主按钮 |
| 比例 | 细条 | 标题下一排**方块分段比例条**，格子里写百分比或体量 |
| 图表 | 水位瓶、细条 | 刻度圆表、带圆点的细竖线、方块条、矩形树图、热力格子 |

## 1. 令牌（[tokens.css](tokens.css)）

- **底色**：整窗 `#E3ECF6 → #F0F4F9 → #F8FAFC`（175°）。
- **卡片**：纯白，一圈 `rgba(17,20,24,.07)` 细线，圆角 10px，阴影几乎为零。每屏一张黑色主卡 `#15181D`，里面的分隔线 `#2A2E35`，次要字 `#9EA6B2`。
- **文字**：墨黑 `#111418`、`#5C6470`、`#9AA2AD` 三级；分隔线 `#E7EBF0`。
- **数据**：四档天蓝 `#7CCBF1`、`#A6DCF7`、`#C8EAFB`、`#E2F3FD`，越深越多；天蓝上的字用深海蓝 `#0F3550`。类别不再各用一种彩色，靠标签、顺序和图例区分。
- **唯一的高亮：柠檬绿** `#D6F03C`。只用在放心清、已选、开关打开、勾选、完成、最近一次、这次腾出的那段；上面的字用 `#1C2400`，淡底标签 `#F1FAC8` 配 `#4A5A00` 字。
- **注意：橙红** `#FF4F2B`。描边表示“要你看”，实心表示问题（删不掉、快满、停下）；淡底标签 `#FFE7E1` 配 `#C2361A` 字，黑卡上用 `#FF8E75`。从不只靠颜色，旁边一定有字。
- **中性**：浅灰 `#D5D8DD`、`#E7E9EC`，表示关、没选、受保护、空格子与没走到的刻度。
- **不再用**：v2 与前几轮的强调蓝、绿、琥珀、红与五类彩色。
- **圆角**：窗口 12、卡片 10、按钮 8（大按钮 10）、开关与分段 6、标签与比例条 4、格子 3。
- **字**：正文 Segoe UI Variable Text / 微软雅黑 UI；数字 Segoe UI Variable Display 细体 300、等宽数字；路径与名字模式用 Cascadia Mono。字号七档：11 坐标与小标签 · 12 次要 · 13 正文 · 15 卡片标题 · 36 卡片数字（黑卡 52）· 40 页标题 · 46 标题旁的大数。粗细只用 300、400、600。

## 2. 骨架（每一页都一样）

窗口按 1240×820 设计，从上到下：

1. **顶栏** 66px：左边冰山标志与 Water；中间导航分段（选中黑底白字）；右边眼睛（只读扫描）与齿轮（在设置页时黑底）。隔离区有东西时，导航里用橙红写体量。
2. **标题行** 96px：左边一行小字（范围、时间）和一句 40px 深色标题；右边三个 46px 细体大数，各带一个小图标和一个词。
3. **比例条**：一排方块分段，宽度按比例，每段上面一个小标签，格子里写百分比或体量；最后可以跟一个固定宽的小格（满的那天、这次一共）。设置页没有大数和比例条。
4. **便当格**：卡片有宽有高、不等分，间距 14px。每屏一张黑色主卡占满一整列的高度，主按钮在它底部；其余是白卡。卡片三段：标题行（图标与标题，右边标签或方形小按钮）/ 内容 / 底栏贴底。同一排卡片底栏对齐。
5. **浮层**：分组抽屉从右侧滑出（480px，圆角 10），确认框居中（600px，圆角 12），后面盖一层 `rgba(17,20,24,.28)`。

**图表**（每种都有文字或数值，不只靠颜色）：
- **刻度圆表**：一圈细刻度，黑色是已用，橙红是快满的那段，柠檬绿是这次腾出的；黑卡里用白刻度。小号（40～96px）用在盘的小卡与列表行。
- **带圆点的细竖线**：每天或每秒一根。清理那天柠檬绿宽条，要注意的橙红宽条，带小气泡写数；预测部分是灰色空心点；坐标标签对准竖线。
- **方块条**：一排小方块，按比例上色；放了几天这类，从第 8 格起变橙红；隔离区最早一批用两行 14 个大方块，一格一天。
- **矩形树图**：面积就是体量；放心清是天蓝三档，要你看是橙红描边，已选是柠檬绿；小块只写数字，名字在悬停提示里。
- **热力格子**：一格一天、一列一周（记录页）。

## 6. 第二轮（11-06 下午，按用户意见）

用户看了第一轮：“整体方向对了，但是我希望有更多的可视化图表内容，现在文字太多了，而且很奇怪‘什么十年之内不会满’这些描述非常奇怪。字体，以及字号，都要再优化，卡片底部要对齐。”

**用图代替句子**（每页至少一张图，图都有文字图例与数值，不只靠颜色）：

| 页 | 图 |
|---|---|
| 首页 | 每个盘一个已用圆环 + 14 天可用空间竖条；“空间去哪了”每盘一条分段条（已用 / 可清 / 可用）；隔离区圆环（放了几天）与每次清理的横条；侧栏“最近几次 · 可清”柱状图 |

| 趋势 | C 盘 30 天面积图，虚线画到满的那天；其它盘各一行小竖条与 30 天变化；一直在长的每行一条小竖条 |

**措辞**：不写“十年内不会满”这类推算句。盘只在真的会满（90 天内）时写“约 23 天后满”，其余只给一个“稳定”小标签和 30 天变化量；数据不够时写“体检次数少，先不预测”。说明文字（“新加的文件夹会单独体检……”“这些不是清掉就完的……”）都删了，靠标签、图例和按钮自己说明。

**字体与字号**：只用每台 Windows 都有的两种：数字与英文 Segoe UI Variable（Display 用于数字，细体 300），中文微软雅黑 UI（大标题用 Light）。字号固定八档：11 坐标轴 · 12 次要 · 13 正文 · 14 卡片标题与强调 · 16 小节标题 · 30 卡片数字（大卡 40）· 40 页头中文标题 · 56 页头数字。粗细只用 300（数字）、400（正文）、600（标题）。

**对齐**：卡片一律“标题 / 内容 / 底栏”三段，底栏贴底（`margin-top:auto`）。同一排卡片等高，底栏、按钮对齐；最后一排撑满到底，和右侧栏底边齐平。

**图表配色**（都用 dataviz 的 `validate_palette.js` 在浅色底上验过：亮度带、彩度、色盲相邻差都通过；对比度不足 3:1 的几色都配了文字图例）：
- 五类：AI 编程工具 `#4F7FEF`、浏览器缓存 `#2FB3A1`、开发缓存 `#9479F0`、安装包 `#EE9B4B`、临时文件 `#E86F9A`，固定顺序，标签、分段条、横条同色；
- 空间分类：放心清 `#2F6FE4`、要你看 `#E9A23B`、只统计 `#9C8FE0`、受保护 `#4A68B0`、系统设置里 `#3BB39E`；
- 状态色（绿、琥珀、红）只表示状态，不拿来当分类色。

## 7. 第三至五轮与定稿（11-06 晚）

- **第二轮被否**：“不行不行，没有任何的设计感，可视化的感觉还没有之前那种音量条好看。你的柱状图，环形图，都还是上个世纪的审美设计了，太丑了。”接着：“你自己看一下我给你的参考图，排版合理，留白很足。清晰大方。”
- **第三轮**把全部图换成第一张参考图那种细竖条（原稿与截图现在在 `round3/`）。做完时用户又发来六张优秀设计：智能家居面板、Crextio 人事面板、Wise 统计、团队表现、UPS 货运、Avito 商品，之后又补了一张带矩形树图与热力格子的流量面板。这些图片只在对话里，没有存盘。
- **从这些参考里读出的规律**（第四轮照此做）：
  1. 每屏一张深色主角卡压住画面，主按钮放在里面；其余卡片白色，个别半透明。
  2. 便当格：卡片有高有宽，不等分。
  3. 深色大标题直接放在浅色底上，右边几个很大的细体数字。整窗是一层浅天蓝渐变，不再分蓝页头与白底板。
  4. 比例用宽窄不一的胶囊条，分深色、强调蓝、琥珀、斜纹、描边五种样式，百分比写在胶囊里。
  5. 图表有性格：
     - 刻度圆表（盘的已用，快满的那段用琥珀）；
     - 带圆点的细竖线（30 天可用空间，清理那天蓝色、今天琥珀色，各带一个小气泡标签）；
