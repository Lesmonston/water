# Water 界面设计 v1

2026-10-26，总控设计；同日按用户两次审稿改为白色磨砂玻璃方向（第 1、2、6 节）。执行者按本文、[tokens.css](tokens.css) 与 [mockup.html](mockup.html) 实现；三者冲突时以本文为准，并交总控订正。数据字段以 [IPC 契约](../../../contracts/checkup-v1/IPC.md) 为准。

## 1. 设计原则

用户 2026-10-26 两次审稿：先要求“磨砂玻璃质感、高级，不要常规 UI”，再要求“磨砂的白感更重，渐变不要花哨，更清爽高级”。本节落实这两条，优先级高于后文细节。

1. **白色磨砂为底。** 层次靠白色玻璃的不透明度、模糊、1px 高光描边与很淡的投影建立；不用色块、粗边框、表格网格。
2. **一个强调色，纯色使用。** 只有深一档的蓝 #1F6FD1，用于主按钮、选中复选框、进度、图表线。按钮、文字、进度条一律纯色，不用渐变，不加光晕。
3. **水是唯一的主视觉。** 磁盘用水位瓶，扫描是一圈上涨的水，清理完成是水位下降；水只用两种浅蓝，不发亮。
4. **数字是主角。** 关键数字用 200 字重的超细大号，墨色纯色；其余文字按 66%、48% 透明度退后。
5. **语义色克制。** 级别只用小圆点 + 文字；增长只用棕橙色文字和一道 2px 细线；危险色只在确认框出现。
6. **先说结论、风险写在按钮旁、默认保守**，沿用不变。

明确禁止：渐变文字、按钮渐变、彩色光晕、焦散或彩虹背景、emoji 图标、默认浏览器控件外观、彩色徽章墙、卡片套卡片、英文装饰眉题。

## 2. 材质与主题

**窗口底材。** Windows 11 上用 Tauri 窗口效果开启 Mica，窗口透明；应用在其上铺一层 86% 不透明的近白底（`--w-window`），再加三团极淡的同色冰蓝柔光和 5% 细颗粒噪点。环境层静止。系统不支持或关闭透明效果时，退化为同一近白底，观感不变。

**玻璃。**

| 层级 | 用途 | 填充 | 模糊 | 圆角 |
|---|---|---|---|---|
| 窗口 | 背景、侧栏 | 近白 86%，侧栏再叠 28% 白 | 60px | 12px |
| 玻璃 | 内容卡、分类卡 | 白 74% 纯色 | 36px，饱和 125% | 20px |
| 浮层 | 详情抽屉、确认框、底部操作坞 | 白 86%～88% | 50px | 22～24px |

每块玻璃：顶部 1px 纯白内高光、整圈 1px 白色描边、5% 细颗粒、低浓度中性投影。玻璃内部的数据条与清单用 3% 墨色底（`--w-surface-sunken`）区分，不再套白卡。

**颜色。** 墨色 #10263F 三层透明度。强调蓝 #1F6FD1（白字 5.0:1），悬停 #1A62BA。级别：推荐清理 #2A9D8F、需要确认 #D49A3E、仅供参考 #9AA7B6、受保护 #8E84D8。增长 #B5652A，危险 #C23B45。水：#9CCBF4 / #6EAEEB / 背景波 #D5E8FA / 可释放层 #CFEDE6。全部取值见 tokens.css。

**字体。** Segoe UI Variable（Display 用于数字与标题，Text 用于正文），中文回退微软雅黑 UI。大数字 200 字重、字距 −0.04～−0.05em；标题 600 字重、字距 −0.02em；数字等宽。不用英文眉题。

**动效。** 水面两层缓慢横移（8 秒与 13 秒）；“开始体检”按钮外一圈淡水波；页面切换 400ms 上浮淡入；抽屉与确认框 220ms 缓出。系统“减少动画”时全部静止。

**性能约束。** 同屏 backdrop-filter 不超过 3 层；列表行不加模糊；WebView2 实测滚动 60fps。

预览图见 `previews/`，由 `scripts/design/render-mockup-previews.mjs` 用私有 Chrome 按 1300×900 生成。

## 3. 窗口与布局

- 默认 1240×820，最小 1040×720。无系统标题栏：40px 透明标题区与 Windows 窗口按钮叠在内容上，可拖动。左侧导航 232px，内容区最大宽 1040px 居中，左右留白 36px。
- 结果页底部是悬浮的玻璃操作坞，不是通栏。
- 不做多窗口；详情用右侧浮层抽屉（宽 500px，从标题区下方开始），确认用居中浮层对话框。

## 4. 导航

左侧五项，细线图标 + 文字：**体检**（默认）、**增长趋势**、**清理记录**、**扫描位置**、**关于与隐私**。选中项是一块小玻璃。底部一块弱玻璃写“本地只读扫描 · 不读取文件内容，不上传任何数据”与版本号。

## 5. 页面

### 5.1 体检首页（未扫描或回到首页）
- 标题“这台电脑的空间，去了哪里”，副文案说明只读取文件名、大小与时间。
- 系统盘大卡：左侧水位瓶（水位 = 已用比例，水面上一道薄荷色透明层 = 上次体检的可释放量），右侧超细大号“59.8 GB 可用”与三项小指标（可放心清理、近 7 天新增、上次体检）。其它固定磁盘为右侧竖排的小玻璃条，剩余不足 10% 时细条变橙。
- “开始体检”是纯色蓝色球形按钮，旁边一句范围说明。
- 若有上次结果：卡片“上次体检 · 10 月 26 日 13:05 · 可放心清理 13.6 GB”，链接“查看结果”。
- 若检测到泄漏：首页顶部橙色横幅（同结果页）。

### 5.2 扫描中
- 左侧水波进度环：外圈纯色细进度弧，内部是随进度上涨的水面，中心超细大号“已发现 19.4 GB”。
- 右侧玻璃卡分类清单，逐项显示状态：等待 / 扫描中（旋转点）/ 完成（体量）。分类顺序与结果页一致。
- 次要信息：已检查 182,340 个文件 · 用时 0:36。
- 次按钮“停止扫描”；停止后进入结果页并标“部分结果”。

### 5.3 体检结果（核心页）
- **主数字区**（不加卡片）：眉题“可放心清理”，下方超细大号“31.7 GB”（墨色纯色），再下一行“C: 15.7 GB · F: 16.0 GB · 扫描于今天 13:05，用时 48 秒”。右侧玻璃卡：本次共识别总量、四段比例条与 2×2 图例；点击图例切换下方过滤。
- **洞察横幅**（仅在有疑似泄漏或持续增长时）：玻璃卡左缘一道 2px 棕橙细线、棕橙线条图标，“C:\Windows\Temp 中的 rb#-x-chrome-* 两天新增 1,970 个（+48 GB），像是某个测试工具的浏览器临时目录没有删除。”按钮“查看修复建议”打开对应分组详情。
- **过滤条**：全部 / 推荐清理 / 需要确认 / 仅供参考 / 受保护；右侧排序“按体量 / 按增长”。
- **分类卡片**（顺序：AI 编程工具、浏览器、系统临时文件、应用更新与安装包、开发缓存、崩溃与日志、显卡与系统缓存、自定义位置、未识别）。卡头：图标、分类名、合计体量、已选体量、全选复选框（只作用于可勾选组）。卡体为分组行。
- **分组行**：复选框 · 标题 + 第三层墨色副行（数量、最近活动；有增长时接橙色“↗ 1.2 GB”；被占用时接“Chrome 正在运行，将跳过占用的项”）· 级别标记（圆点 + 文字）· 右侧体量（Display 字体）· 细箭头。受保护和仅供参考的行用锁 / 信息图标代替复选框，标题与体量退到第二层墨色。
- **底部操作坞**：“已选 13 组 · 31.7 GB”、玻璃次按钮“重新扫描”、主按钮“清理所选”（未选时禁用）。

### 5.4 分组详情（右侧抽屉）
- 级别标记、标题、归属与文件数；三格数据条（占用、最近活动、可清理 / 总数）。
- 三段说明：**这是什么**、**为什么可以清**（或为什么受保护）、**清理后会怎样**（如“不会退出登录；首次打开网页稍慢”）。
- 数据：最早 / 最近活动时间、可清理项数 / 跳过项数（年龄未到、正在使用）。
- 前缀分布（有时显示）：如“rb#-x-chrome-* 1,970 个 · 48 GB · 最新 2 分钟前”。
- 项目清单：最多 200 行，路径（中间省略）· 体量 · 最近活动；超出写“另有 1,770 项”。
- 增长：与上次体检相比 +x GB / +n 项。
- 修复建议（仅泄漏类）：浅橙底代码块，文字可复制，按钮“复制给项目维护者”。
- 受保护组底部固定说明：“Water 不会清理此类数据。”

### 5.5 确认清理（浮层对话框）
- 标题“永久删除 31.7 GB？”，下一行组数与项数。
- 所选分组清单放在一块内嵌浅玻璃里（名称 · 体量），需要确认级别的组带琥珀圆点，被占用的组附一句“运行中，占用的项会跳过”。
- 红色提示行（红字 + 警示线条图标 + 由浅红渐隐到透明的底）：“这些文件将被永久删除，不进入回收站，无法恢复。”
- 灰色说明：“执行前会再次检查每一项；正在使用、刚有改动或已经变化的项会自动跳过。”
- 按钮：玻璃次按钮“取消”，红色主按钮“永久删除 31.7 GB”。按钮文案必须带体量。

### 5.6 清理中
- 与扫描中同一水波进度环，但水面随进度下降，中间“已释放 4.2 GB”，下方当前分组与进度“第 3/6 组”。
- 次按钮“停止”：完成当前一项后停止，结果页如实显示未处理项。

### 5.7 清理完成
- 主卡：超细大号“31.2 GB 已释放”，右侧每个涉及的磁盘一只水位瓶：虚线标出清理前水位，实际水面已下降；瓶下写“C: 59.8 → 75.0 GB”。
- 分组结果玻璃列表：绿色细线勾 = 已清理；琥珀警示图标 = 部分完成（跳过 6 个配置：正在使用）；红色叉 = 失败（原因白话）。
- 说明“预计 31.7 GB，实际 31.2 GB；差额来自跳过的项”。
- 按钮“查看清理记录”“回到结果”。

### 5.8 增长趋势
- 折线图：每次体检时的 C 盘可用空间（最近 30 天）。
- 增长榜：与上次体检相比增长最多的分组，列体量变化、项数变化、日均速度。
- 疑似泄漏卡片：名称、速度（如“约 17 GB/天”）、来源推断、修复建议入口。
- 少于两次体检时显示空态：“再体检一次就能看到变化”。

### 5.9 清理记录
- 时间倒序列表：时间、清理组数、释放体量、跳过项数。点击展开每组结果与日志位置。

### 5.10 扫描位置
- 系统位置按分类开关（默认全开，受保护类只扫描体量，不能关闭说明）。
- 自定义文件夹：列表 + “添加文件夹”（打开系统文件夹选择框，由后端打开，不接受手输路径）+ 移除。说明：“在自定义文件夹里只识别带缓存标记的构建目录、测试浏览器配置等明确的开发垃圾。”

### 5.11 关于与隐私
- Water 读取什么：文件名、大小、时间、属性；正在运行的程序列表（用于判断是否占用）。
- 不读取什么：文件内容、浏览器登录信息与网站数据、聊天记录内容。
- 不上传任何数据；删除只在你确认后执行，不可恢复。

## 6. 组件

- **按钮：** 主按钮为纯色强调蓝胶囊（1px 内高光、淡投影）；次按钮为白色玻璃胶囊；危险按钮纯色红，仅确认框；文字按钮。按下缩放 0.98。
- **球形按钮：** 仅首页“开始体检”，直径 88px，纯色强调蓝，外有一圈淡水波。
- **复选框：** 18px 圆角方形，未选为白底细描边，选中为纯色强调蓝 + 白勾；半选为白色短横。受保护行换成紫色细线锁图标，仅供参考行换成灰色信息图标。
- **级别标记：** 7px 纯色圆点 + 文字，无光晕。**增长标记：** 橙色斜上箭头 + 数值。**占用提示：** 第三层墨色文字，不用标签。
- **分类卡：** 玻璃卡，卡头为白色圆角图标底座（墨色线条图标）+ 名称 + 副标题 + 右侧合计（Display 字体）。行之间只有 1px 极淡分隔，悬停时行变成浅玻璃。
- **结果比例条：** 8px 高四段纯色圆角细条，段间 3px 空隙，下方 2×2 图例。
- **底部操作坞：** 悬浮胶囊玻璃，居中，距底 22px：已选组数、体量、重新扫描、清理所选。
- **水位瓶、水波进度环：** SVG 实现，液体两种浅蓝，水面两层波纹，瓶身只有很淡的左右高光；可释放部分是水面上一道浅薄荷色层。进度环外圈为纯色细弧。
- **抽屉、确认框：** 浮层玻璃；背后内容加 2px 模糊和极淡的近白蒙层。抽屉从标题栏下方开始，不遮窗口按钮。
- **分段控件、开关：** 玻璃底槽，选中段为白色实心胶囊；开关开启为纯色强调蓝。
- 全部图标为统一的 1.5px 细线 SVG（24 网格、圆角端点），不用 emoji、字体符号或位图。

所有交互组件都有：默认、悬停、按下、聚焦（3px 强调蓝描边光圈）、禁用（墨色 28%）。
## 7. 文案与格式

- 体量：≥1 GB 写一位小数“13.6 GB”，<1 GB 写整数“820 MB”，<1 MB 写“<1 MB”。合计与明细四舍五入后可能差 0.1，不强行凑平。
- 时间：一天内写“2 小时前”，其后写“10 月 25 日”，超过一年写年份。
- 数字千分位：69,947。
- 级别名、按钮名按本文固定，不同页面不改说法。
- 错误白话化：“没有权限读取 3 个文件夹，已跳过”，不显示系统错误码。

## 8. 交互规则

- 默认勾选所有“推荐清理”组；用户改动后保留到下次扫描前。
- 被程序占用的组仍可勾选，行内灰标“Chrome 运行中，将跳过”，确认框再提醒一次。
- 扫描或清理进行中，导航可切换，但不能再次开始；回到体检页显示进行中状态。
- 关闭窗口时若正在清理，先弹框“清理正在进行，停止后再关闭？”
- 键盘：Tab 顺序与视觉一致；空格切换复选框；Enter 打开详情；Esc 关闭抽屉和模态框。进度更新用 aria-live="polite"。

## 9. 与后端的边界

界面只发送分组 ID、计划 ID 和确认令牌，从不发送或拼接路径；“添加文件夹”由后端打开系统选择框。界面显示的路径只用于阅读。所有数据通过 IPC 获取，不读写本地文件，不联网。
