# Flick 推特小视频（定稿，2026-11-08）

- **用户要求**：
  - “你趁现在做个小视频，我发个推，谦虚一点，主体就是做了个清理的小工具，目前还在调整，然后你结合一下目前的功能，尤其是针对AI编程人员的痛点来写，先写个稿。整体的风格是留白，高级的产品介绍风格。”
  - “不一定是C盘吧，主要介绍一下我们会查出来什么垃圾。”
  - “照这稿做视频”。
- **规格**：约 40 秒，16:9，1920×1080。
- **风格**：
  - 白底或很浅的雾白，大段留白，一屏一句，细字；
  - 0.6～0.8 秒淡入淡出加轻微位移，不闪不跳，不用表情符号；
  - 界面画面用定稿的毛玻璃卡片（[设计 v3](../design/water-ui-v3/DESIGN.md)），logo 用“一笔弹出”（[品牌](../design/flick-brand/BRAND.md)）；
  - 七类那一段每屏版式完全一致，只换字；
  - 背景音乐可有可无，有的话很轻。

## 推文正文

> 做了个清理磁盘的小工具，叫 Flick，还在调。
>
> 写代码的电脑满得快，大头往往是这些：Claude Code、Codex、Cursor 的旧版本和升级残留，npm、pip、cargo 的缓存，项目里的 target 和很久没动的 node_modules，测试用的浏览器配置，还有一直在长、没人收拾的临时目录。
>
> Flick 先只读体检，再告诉你哪些能放心清、哪些要你看一眼、哪些不碰。清掉的先进隔离区，随时还原。一直在长的目录会给一段线索，丢给 agent 去查根因。
>
> 目前只有 Windows，界面只有中文。

## 制作要点

- **界面画面不能用整合的截图**：那些截图里有本机真实路径。等第十三波 U1（界面样例换成虚构路径）合入后，用新样例在浏览器里重新截；也可以先做不需要界面的那几屏。
- **本机没有 ffmpeg**（11-08 查过）：把画面合成视频要用它或别的编码工具，下载前先问用户。
- **建议做法**：
  1. 每一屏写成一个静态 HTML 页（同一套字体与留白）；
  2. 用浏览器按帧截图，界面那几屏用真界面加虚构样例；
  3. 再合成视频。
  
  先给用户看几张关键帧，确认后再出整段。
- **出视频前再核一遍**：画面里没有用户名、本机路径、本机项目名。
