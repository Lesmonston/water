# ADR-001：独立内核与分阶段开放清理

日期：2026-10-17。状态：采纳为立项基线；技术栈在 M1 验证后锁定。

## 决策

1. Water 建立独立 Git 仓库和独立安全内核，先不 fork 任一上游作为产品。
2. 静态研究五个项目并固定commit，结论和代码输入分开；第三方 checkout 不纳入产品发布。
3. 暂选 Rust + Tauri 2 + TypeScript/React；先只读核心与fixture验收，再接桌面，最后开放特定清理动作。
4. 首版双平台，跨平台共享规则与契约，平台身份/容量/恢复实现各自验证。
5. 本阶段不复制第三方代码、规则清单或UI文案；任何后续引入单列来源、许可、测试和NOTICE要求。

## 理由

已有项目可帮助理解交互和规则覆盖，但我们的主张需要更强的对象身份、已知引用、容量真实性和执行边界。直接继承任一项目会同时继承其规则假设、执行语义和许可义务，不能通过换名保证安全或差异。

## 代价与回退

独立内核增加初期成本；M1 若发现 Rust/Tauri 成本超过收益，再用新ADR调整，不先投入完整UI或支付体系。暂不承诺任何框架自动提供清理安全。允许后续引入审查合格的MIT/Apache组件，但不隐瞒复用。
