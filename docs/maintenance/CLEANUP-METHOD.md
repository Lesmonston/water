# 总控清理的固定做法

2026-11-02 起用。来源：四个盘与 `denglou` 这一轮的经验（[清理记录](CLEANUP-20261101.md)启发第 25～37 条），以及 `denglou` 总控[收尾回执](../../../../denglou/worktrees/ui-v2/docs/ops/WATER-CLEANUP-RECEIPT-20261102.md)第 3 节（用户 11-02 转来，要求并入）。Water 认得出的交给 Water 清；认不出的由总控按本文做。能做进产品的，第十波逐步收进 Water（见[下一轮计划](../dispatch/wave9/PLAN.md) 4.2）。

## 红线

- 真实用户数据只读；浏览器登录数据、会话受保护。
- 总控不直接删除：要么用户在 Water 里按清理，要么总控移到同盘隔离区，由用户核对后自己删。
- 用户按编号选（A～E 分级表），选择的原话写进记录。
- 别的项目：用户选中的由 Water 总控执行，事后给该项目总控写知会；不改它的代码。

## 步骤

1. **普查**：只读名字、大小、时间、属性；不跟联接；硬链接按文件 ID 只算一次（[deep-survey.cjs](../acceptance/wave8/controller/cleanup-20261101/deep-survey.cjs)）。
2. **分级表**：A～E，逐项编号。请别的项目总控出分级回执时，要求每行写明“git 忽略的贵重件：无 / 有（列名）”（回执 3.2）。
3. **用户选择**：原话入记录。
4. **现场重新生成清单**：分级表一小时内就会和现场对不上，执行时按规则重新生成，逐条重查前提（启发第 29 条）。泄漏按严格模板挑成员，不整个父目录搬（第 28 条）。
5. **挪前的闸**（[precheck-plan.cjs](../acceptance/wave8/controller/cleanup-20261101/precheck-plan.cjs) `--plan`，输出存到计划旁边，删除前留有文件级的底）：
   - `IN` **入向联接**：有别处的联接指向候选时，把链解到最终目标，在执行单里写“X 改指 Y 后再清”，交所属项目总控改指；这一项先列为延后（回执 3.1，第 35 条）。
   - `KEEP` **贵重件名**：签名、证书、私钥（`*.jks`、`*.keystore`、`*.p12`、`*.p8`、`*.pem`、`*.mobileprovision`）、`.env*`、`credentials*`、本机数据库。只列名，不打开，交所属项目总控判断；回话前这一项延后（回执 3.2，第 36 条）。
   - `NAME` **保留名**（`nul`、`con`、`aux`、`prn`、`com1`～`com9`、`lpt1`～`lpt9`，以及结尾是点或空格的名字）：记下来，交付时用 `\\?\` 命令（回执 3.4，第 34 条）。
   - **在用**：查进程的可执行文件和命令行，`F:\x`、`F:/x`、`/f/x` 三种写法都要认（第 26 条）。别的总控正在用的服务器、模拟器、数据库目录不碰（第 27 条）。模拟器快照要等模拟器退出、启动参数改成 `-no-snapshot` 后再清，否则列为延后（回执 3.6）。
   - **工作树**：分支在远端、没有未提交改动、未跟踪文件别处有副本（第 25 条）。已脱离 git 的目录查不了，只能靠 `KEEP` 名单加项目总控确认：“脱离 git”不等于“没用”。
6. **压缩归档**：先写 `.partial`，重新打开核对名字与大小、`testzip`，通过后改名，再隔离原目录；原位置留索引（第 30 条）。
7. **隔离**：[quarantine-listed.ps1](../../scripts/maintenance/quarantine-listed.ps1)，同盘，放在 `<编号>\<原路径>`，逐项写日志。
8. **挪后复查**：用 [links-into-moved.cjs](../acceptance/wave8/controller/cleanup-20261101/links-into-moved.cjs) 查断链，有就当场移回（第 32 条）。隔离区里的联接逐个确认是重解析点后，做不递归的删除，只去掉联接本身（第 32 条、回执 3.5）。
9. **执行结果表**：每项一行。延后项写明“解除条件”和“谁来收尾”，例如“模拟器关机后 / `denglou` 总控”“某联接改指后 / 项目总控”（回执 3.3、第 37 条）。
10. **交付**：`precheck-plan.cjs --handover <隔离目录>` 要求 0 个联接，保留名照实列出。给用户的删除命令默认带前缀：`cmd /c 'rd /s /q "\\?\<盘>:\_water-quarantine-…"'`。PowerShell 里的 `rd` 是 `Remove-Item`，要经 `cmd /c`。
11. **删后核对**：目录已不在，可用空间与预计相符。有残留时用 node 或 `cmd` 查：PowerShell 的 `Get-Item` 读不出保留名文件的属性（第 34 条）。
12. **记录**：清理记录、执行单、`STATUS`、记忆；给相关项目总控写知会转贴语。
