# WATER-W4-G3 界面修补 SPEC（`apps/water/ui` 第 2 版）

2026-10-26 冻结，总控（Claude）。修两处在 F3 自测的真实窗口截图里看到的问题，并把操作坞的间距锁成回归断言。本文在 [UI](../checkup-v1/UI.md) 之上逐条覆盖；没提到的地方 UI 原文、[设计说明](../../docs/design/water-ui-v1/DESIGN.md)、tokens 与静态稿继续有效，这些文件本身都不改。

## 1. 范围与不变的东西

- 只改 `apps/water/ui/`。
- 以下全部不变：
  - [IPC](../checkup-v1/IPC.md) 与 [ui-fixtures.json](../checkup-v1/ui-fixtures.json)；
  - `styles/tokens.css`（仍须与设计 tokens 逐字节相同）；
  - 页面结构、配色与视觉语言：白色磨砂、纯色强调、无渐变光晕、无 emoji。
- **整机检查依赖的文字与名字一律不变**。F3 的整机观察器按名字找控件、等文字出现，下面 11 处一个字都不能动：

| 种类 | 文字 |
|---|---|
| 按钮 | 开始体检、清理所选 |
| 导航链接 | 增长趋势、清理记录、扫描位置 |
| 页面文字 | 开始一次体检；本次体检共识别；比较每次体检，找出一直在变大的东西。；每一次体检与清理，都有迹可循。；选择体检要看的地方。受保护的数据只统计占用，永远不会被清理。 |
| 失败提示 | 体检未能完成，请重新体检。 |

  另外，点“清理所选”后，服务返回的 message_zh（M1 为“这一版只做体检，清理功能会在下一版开放。”）仍要原样显示在结果页上。

## 2. 结果页操作坞的间距（回归锁定，不是修复）

总控自测时实测过：
- 页面底部已留 124 px，结果页滚到底时，最后一个分组行与操作坞之间有空隙，**现状已满足**。
- F3 截图里操作坞盖住的，是滚动途中从它下面经过的行，属于浮动操作坞的正常表现。

本票不改操作坞，只把现状锁成测试断言：结果页滚到底时，**最后一个分组行的下边缘至少比操作坞的上边缘高 16 px**，1240×820 与 1040×720 都成立。修改别处样式时不得破坏这一条。

## 3. 提示条只属于当前页面

现状：命令出错后，页面顶部的提示条（`#notice`）在切换页面后仍然留着。比如在结果页点“清理所选”得到 M1 的提示，再去增长趋势、清理记录，提示还在。

要求：
- **路由切换时清掉错误提示**：`state.error` 产生的提示条，在 hash 路由变化后不再显示。
- 连接类提示不受影响，切换页面仍保留，直到状态恢复：“正在重新连接 Water 服务…”与“未能读取任务进度，请重新连接。”及其“重新连接”按钮。
- 回到结果页时不重新显示旧提示；再次点“清理所选”时照常显示服务返回的句子。
- “结果已过期，请重新体检后再清理。”这类结果页正文里的说明（`state.stale`）不属于提示条，规则不变。

## 4. 两段说明文字不留短孤行

现状：
- 侧栏底部“不读取文件内容，不上传任何数据”折成两行，第二行只剩一个“据”字（实测 1240×820 下为 14 字加 1 字）。
- 首页系统盘卡片的说明“共 … GB，已用 …%。体检后可查看能够清理的空间。”的末行只剩“空间。”。

要求：
- 在 1240×820 与 1040×720 下，这两段文字的每一行至少 4 个字符。
- 文字内容不变，字号与颜色仍只用 tokens。
- 做法不限。总控实测：`text-wrap: pretty` 对这两段中文不起作用，`text-wrap: balance` 可以。

## 5. 测试

- `tests/unit.test.mjs` 精确 3 个，不变。
- `tests/browser.test.mjs` 由 4 个变为**精确 5 个**：原 4 个不改名、断言继续成立，新增 `ui_m1_polish`。

`ui_m1_polish` 用假宿主（只在测试文件里）至少覆盖下面三组，失败信息含对应标记：

| 标记 | 断言 |
|---|---|
| `UI_DOCK_CLEARANCE` | 让假宿主的扫描结果足够长，一屏放不下（例如在测试里复制若干分组，ID 保持合法且不含路径）。在 1240×820 与 1040×720 下把结果页滚到底，用 `getBoundingClientRect` 量出最后一个分组行与 `.dock`，前者的 bottom ≤ 后者的 top − 16。（回归锁定，现状即通过。） |
| `UI_NOTICE_SCOPE` | 1. 假宿主让 `clean_prepare` 返回 `{code:"unavailable", message_zh:"这一版只做体检，清理功能会在下一版开放。"}`；点“清理所选”，提示条显示这句。<br>2. 切到增长趋势：提示条隐藏，页面上没有这句。<br>3. 回到结果页：仍没有这句。<br>4. 进度读取暂停时的“未能读取任务进度，请重新连接。”在切换页面后仍在。 |
| `UI_FOOTER_WRAP` | 在两种尺寸下，用 Range 的 `getClientRects` 按行统计侧栏底部说明与首页系统盘说明（尚未体检时的那句），每行至少 4 个字符。 |
