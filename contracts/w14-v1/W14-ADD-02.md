# W14 补充 02：宿主不加 `system_language`（冻结）

2026-11-08，总控（Claude）冻结。改 [W14](W14.md) 第 4.1 节，W14 其余部分与[补充 01](W14-ADD-01.md) 不变。

## 0. 为什么改

- W14 第 4.1 节要宿主在 `app_info` 里给出 Windows 用户首选界面语言。Windows 上取这个值要调系统函数，而宿主的 `lib.rs`、`main.rs` 都是 `#![forbid(unsafe_code)]`，检查器也不许宿主有原生模块；宿主现有的依赖里也没有现成读语言的包。
- 界面（U1，已合入）第一次打开时取 `app_info.system_language`，没有就用 `navigator.language`。WebView2 没设语言时按 Windows 显示语言运行，`navigator.language` 应当就是系统语言。
- 为这一个值另开原生包的单不划算，先按 WebView 的语言走，在真宿主上核对。

## 1. 改成

- 宿主的 `app_info` **不加** `system_language`，键照旧（`name`、`version`、`license`、`homepage`）。
- 第一次打开的语言由界面按 `navigator.language` 判断，规则照 W14 第 1.1 节（以 `zh` 开头为中文，否则英文）。
- 第十二次整合在真宿主上核对：不设语言、新数据目录打开时，界面语言与 Windows 显示语言一致。不一致时再出单，在已有原生包里加读取，宿主照 W14 第 4.1 节原文补上。

## 2. H1 其余照 W14 第 4.2、4.3 节

`IpcFailure.message_en`、宿主自己的错误英文、`HostPicker::pick` 构造 `IpcError` 时带英文、安装包中英两种语言。
